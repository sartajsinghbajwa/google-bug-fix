# Honestly Zen Event Planning — Vendor Product & Usability Update

Install **on the existing WHC staging app** using the **patch ZIP** and the one-time additive `EventOS-prepare-Vendor-Product-UX-MariaDB.py` script **before restart**.

This update extends vendor listings with service packages, highlights, inclusions, FAQs, lead times and a managed photo gallery; improves the community posting form and insertion; adds contextual form guidance and safe removal controls; and standardizes public blog/marketing/vendor navigation.

See the separate deployment guide `HonestlyZen-Vendor-Product-UX-WHC-Install.md` and regression summary `HonestlyZen-Vendor-Product-UX-Test-Report.md`. Keep `EVENTOS_PRODUCTION_MODE=0` until the WHC production launch checks are separately verified.
